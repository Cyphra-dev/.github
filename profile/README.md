# Cyphra

Open-source tooling for building on Neo4j with TypeScript.

- **[cyphra](https://github.com/Cyphra-dev/cyphra)**: a typed ORM for Neo4j. Describe your graph in a
  `.cyphra` schema, get a generated TypeScript client, and evolve the database with schema-diff migrations.
- **[operator](https://github.com/Cyphra-dev/operator)**: a Kubernetes operator that runs Neo4j Community
  instances, with generated credentials, TLS, and scheduled backups to S3.

Both are free and open source. Issues and contributions are welcome.
